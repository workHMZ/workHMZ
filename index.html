R2FileBox

Vue · Workers · R2 · D1

File sharing built for interrupted connections.

Resumable uploads in 8 MiB chunks, pickup-session accounting and content deduplication. Retryable cleanup handles the less visible part of storage: keeping metadata and objects in sync after partial failures.

Engineering focus: resumability, state consistency and recoverable cleanup.
